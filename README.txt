FRESORA WEBSITE
================

This is a responsive working prototype for Fresora.

Included:
- Responsive landing page
- Search and category filters
- Surplus-food listing cards
- Working cart and demo checkout
- Business partnership form
- Impact section
- Mobile-friendly design

IMPORTANT FOR QR:
A QR code needs a public web address. This package does not pretend that a
local file is publicly hosted.

Easiest free deployment:
1. Create a GitHub repository.
2. Upload index.html.
3. In GitHub: Settings -> Pages -> Deploy from branch -> main/root.
4. GitHub will give you a public URL such as:
   https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
5. Put that URL into a QR-code generator, or send it to ChatGPT and ask for
   a QR code for that exact URL.

You can also deploy the folder on any static hosting provider.
